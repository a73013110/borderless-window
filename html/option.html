開啟模式 按下右鍵選單時，如何處置當前分頁

子母畫面（Beta）：右鍵選單也有「子母畫面開啟（Beta）」入口。
• 右鍵選單一律直接開啟（右鍵動作本身就是頁面 user gesture）。
• 擴充功能按鈕需頁面有近期點擊紀錄才能直接開啟；冷頁面（剛載入未互動）會先顯示「點此啟動」浮窗， 點它才會啟動 PiP — 這是 Chrome 對 PiP 的安全限制，無法繞過。
• SPA 網站（Google、Gmail 等）內容多由 JS 動態渲染，搬到 PiP 後因 CSP 安全限制無法執行， 可能空白或不完整 — 純文章類靜態頁（Wikipedia、MDN）效果最好。
